# Google speech engines. Identical to requirements-api.txt — kept because the two
# Google paths authenticate differently, and that is worth spelling out somewhere.
#
#   --engine gemini          needs only GEMINI_API_KEY in your .env.
#                            Also powers --research and --normalize gemini.
#
#   --engine google-cloud    needs Application Default Credentials — its REST API
#                            rejects plain API keys. This is the path with the
#                            permanent free tier (4M Standard / 1M WaveNet
#                            characters a month), so it is worth the extra setup:
#
#                                gcloud auth application-default login
#                            or  export GOOGLE_APPLICATION_CREDENTIALS=/path/sa.json
#
# Neither runs anything locally.
-r requirements-api.txt
